= Standorte in StorageGRID hinzufügen
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Sie müssen mindestens einen Standort erstellen, wenn Sie StorageGRID installieren. Sie können weitere Standorte erstellen, um die Zuverlässigkeit und Storage-Kapazität Ihres StorageGRID Systems zu erhöhen.

.Schritte
. Auf der Seite „Sites“ den *Site name* eingeben.
. Um zusätzliche Standorte hinzuzufügen, das Pluszeichen neben dem letzten Standorteintrag auswählen und den Namen im neuen Textfeld *Site name* eingeben.
+
Fügen Sie so viele zusätzliche Standorte wie für Ihre Grid-Topologie hinzu. Sie können bis zu 16 Standorte hinzufügen.

+
image:3_gmi_installer_sites_page.gif["Dieses Bild wird durch den umgebenden Text erläutert."]

. Wählen Sie *Weiter*.
